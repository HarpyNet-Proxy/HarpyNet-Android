# HarpyNet VPN для Android

Официальное приложение сервиса HarpyNet VPN для Android.

HarpyNet VPN — быстрый и удобный доступ к интернету с защитой соединения. Для использования приложения необходима активная подписка HarpyNet VPN.

## Скачать

Последняя версия приложения доступна в разделе **Releases** справа на странице.

Для большинства современных смартфонов подходит файл с пометкой **arm64-v8a**. Если вы не знаете архитектуру своего устройства, скачайте **universal**.

## Как начать

1. Оформите подписку HarpyNet VPN.
2. Скачайте APK из последнего релиза.
3. Установите и запустите приложение.
4. Добавьте полученную подписку и подключитесь к VPN.

> Приложение находится на стадии BETA. Перед обновлением рекомендуется не удалять установленную версию, чтобы сохранить настройки.
